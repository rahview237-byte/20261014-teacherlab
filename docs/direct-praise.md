# 코드 없는 직접 적립

2026-10-14 사용자 변경 요청. 과거 명세의 칭찬 코드 및 네 영역 합산 하루 2회 정책을 대체한다.

- 학생 로그인 PIN과 교사 로그인 비밀번호는 유지한다.
- 교사의 칭찬 코드 생성·표시 및 학생의 코드 입력·검증을 모두 제거한다.
- 로그인한 학생은 영역의 버튼을 눌러 자기 칭찬판에 바로 +1 적립한다.
- 하루 한도는 학생·한국 날짜·영역별 각각 2회다. 네 영역 합계로는 최대 8회다.
- 어느 한 영역을 2회 사용해도 다른 영역의 적립은 막지 않는다.
- 네 영역 각각 학기당 30개 상한은 유지한다.
- 교사 일괄 칭찬은 학생 직접 적립 횟수와 별도다.
- 교사가 취소하면 보유 개수만 줄어들며 해당 영역의 당일 사용 횟수는 복구하지 않는다.
- 자정이 지나면 영역별 일일 사용량은 초기화되고 학기 누적은 유지된다.

샘플 로직 검사에서 영역별 3번째 요청 거부, 다른 영역의 2회 적립, 합계 8회, 학생별 분리, 취소 후 사용량 유지, 날짜 경계 및 30개 상한을 검증한다.

현재 샘플은 메모리에 저장하므로 새로고침·다른 기기 간 제한이 유지되지 않는다. 실제 서비스에서는 위 키의 사용량과 칭찬 기록을 서버 트랜잭션에서 함께 갱신해야 한다.
