# 대시보드 화면 변경 명세

최신 변경(2026-10-14): [학생 로그인·직접 적립 명세](./login-and-self-praise.md)를 우선 적용한다. 로그인 후 네 영역은 각각 30칸 가로 막대와 획득 숫자로 표시한다. 원형 스탬프는 사용하지 않는다. 교사 체험 체크박스는 별도의 로그인 화면으로 대체한다.

2026-10-13 사용자 확정 사항. 기존 문서의 학생 대시보드 구성과 충돌하면 이 명세를 우선 적용한다.

## 첫 화면

- 제목은 ‘우리 반 학급 규칙’을 유지한다.
- 자주적인 어린이, 긍정적인 어린이, 적극적인 어린이, 배려하는 어린이 카드에 해당 영역의 내 칭찬판을 바로 표시한다. 별도 메뉴나 영역 탭을 눌러야 볼 수 있는 구조를 사용하지 않는다.
- 학생별·학기별·영역별 30칸과 현재 누적 개수를 표시한다. 네 영역의 기록은 서로 독립적이다.
- ‘오늘의 우리 반’은 기존 하단 위치를 유지하며 ‘우리 모둠’, ‘학급온도계’ 두 항목만 동일한 크기의 큰 버튼으로 배치한다.
- 칭찬 소식과 비밀편지는 현재 제품 범위에서 제거한다. 기존 구현 계획의 해당 기능과 검수 항목은 범위 재정리 전까지 구현 대상에서 제외하며, 검수 통과로 간주하지 않는다.

## 우리 모둠

- 기존 ‘오늘의 우리 반’ 영역에서 진입하는 위치를 유지한다.
- 정리와 다했어요를 각각 학기당 최대 15개로 유지한다.

## 학급온도계

- 아래쪽 둥근 구와 위쪽 세로 관으로 실제 온도계 형태를 표현한다.
- 빨간색 온도 표시가 아래에서 위로 채워진다. 숫자도 함께 표시한다.
- 0~100도 범위에서 5도마다 눈금을 표시하고 선생님의 학급 전체 칭찬 한 번에 5도씩 증가한다.
- 5도부터 100도까지 20개의 보상 입력칸은 처음에는 모두 빈칸이다.
- 개인·모둠 도장은 온도계에 자동 합산하지 않는다.

## 구현 시 성공 조건

- 첫 화면에 네 칭찬판이 동시에 표시되고 각 판의 칸 수는 정확히 30개다.
- 하단 메뉴는 우리 모둠과 학급온도계 두 개뿐이다.
- 개인 30개, 모둠 각 15개, 온도 100도의 상한을 초과하지 않는다.
- 온도 증가와 취소가 각각 +5, -5이며 0도 아래로 내려가지 않는다.
- 보상 입력칸은 정확히 20개이고 초기 내용은 빈 문자열이다.
- 좁은 화면에서 카드와 버튼이 잘리지 않고 키보드로 조작할 수 있다.

현재 산출물은 상호작용 샘플이다. 서버 저장, 실제 권한 검사, 브라우저별 화면 검수는 앱 구현 단계에서 수행한다.
